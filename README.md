# GnidDOS (16-bit ASM)

Мини DOS-подобная система в boot sector на ассемблере x86 (real mode).

## Управление

После загрузки виден промпт `A>`. Введите одну клавишу и нажмите Enter:

- `H` — показать команды
- `L` — очистить экран
- `B` — пасхалка `br br patapim`
- `G` — пасхалка про кота бенгала
- `T` — пасхалка про историчку
- `C` — пасхалка про Canon Zoom Lens

## Сборка

```bash
make
```

## Запуск

```bash
make run
```

Требуются `nasm` и `qemu-system-i386`.
